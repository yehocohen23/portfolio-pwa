# ניתוח תיק — אבטיפוס v1 (מקומי בלבד)

PWA סטטית בעברית (RTL), ללא שרת וללא תלויות. ניתוח והמלצה בלבד — אין מסחר, אין העברות, אין חיבור לחשבונות.
כל נתוני התיק נשמרים ב-localStorage במכשיר. **כל הנתונים המצורפים מדומים.**

## הרצה מקומית
    python3 -m http.server 8765 --bind 127.0.0.1   # ואז http://127.0.0.1:8765/
    node scanner/scan.mjs                          # מחולל מחדש את data/signals.json המדומה
    cd tools && node test.mjs                      # בדיקת דפדפן 390x844 + צילומי מסך

## מבנה
- `index.html`, `styles.css`, `manifest.webmanifest`, `sw.js`, `icons/` — מעטפת PWA (CSP קשיח, בלי משאבים חיצוניים).
- `js/logic.js` — נוסחאות היועץ (T1–T3, DD, צהוב/אדום, מזומן, דמי ניהול, רקורסיית תחזית). משותף לאפליקציה ולסורק.
- `js/app.js` — מסכים: תיק, התראות, סריקה, תחזית, יומן, עוד (שאלון, הגדרות, ייבוא CSV, ספים, גיבוי).
- `js/sample.js` — תיק מדומה. `data/signals.json` — אותות מדומים לרשימה רחבה. `data/sample-import.csv` — דוגמת ייבוא.
- `scanner/` — STUB לסורק GitHub Actions עתידי (לא פעיל, ללא קריאות רשת).
- `tools/` — בדיקות בלבד (playwright-core), לא חלק מהאפליקציה.
